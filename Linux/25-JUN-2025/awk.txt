what is the use of awk command ?

awk command is used to reads the input line by line and converts each line into fields and allows operations on them.

 It is mainly used for manipulating the structured text files like csv, log, etc,...

--> to create csv file from the text file you should use this command "awk '{print $1 "," $2 "," $3}' file.txt > file.csv

1.awk '{print $1, $3} file.txt - to print the 1 to 3 columns from a file.

2.awk -F ',' '{print $2}' file.csv - to print the data when we have a spectator instead of space.

3.awk '$3 > 80 {print $1, $3}' score.txt - to print by a condition.

4.awk '{print NR, $0} file.txt - to print the line numbers.

5.awk '{sum += $2} END {print "Total:", sum}' - to calculate the sum of the column.

6.awk 'BEGIN {print "Name Age"} {print $1,$2} END {print "Done"}' file.txt - to print the begging and ending.

7.awk '/a/' file.txt - to print the matching line of the string.

8.awk '!/a/' file.txt - not to print the matching lines of the string.
